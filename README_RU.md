# ProjectEpoch-Ru

Аддон переводит тексты заданий и подсказки предметов в англоязычном клиенте
WoW 3.3.5a. Он рассчитан на классический интерфейс `30300` и отдельно
поддерживает пользовательский контент приватного сервера.

## Установка на macOS

1. Откройте Finder и перейдите в папку клиента.
2. Скопируйте целиком папку `ProjectEpoch-Ru` в `Interface/AddOns`.
3. Итоговый путь должен выглядеть так:
   `World of Warcraft/Interface/AddOns/ProjectEpoch-Ru/ProjectEpoch-Ru.toc`.
4. Запустите клиент, откройте «Модификации» на экране выбора персонажа и включите
   `ProjectEpoch-Ru`. Если потребуется, включите устаревшие модификации.

Для этого проекта тестовый клиент находится в:
`/Users/graphmachine/Desktop/New Folder With Items`.

## Команды

- `/ruql` — справка и версия;
- `/ruql toggle` — русский текст / оригинальный текст;
- `/ruql id` — ID открытого задания;
- `/ruql missing` — число собранных неизвестных заданий;
- `/ruql on` и `/ruql off` — включить или выключить перевод.
- `/ruql collect status` — статистика собранных данных;
- `/ruql scan achievements` — собрать достижения и критерии;
- `/ruql scan interface` — собрать тексты именованных элементов окон;
- `/ruql scan globals` — собрать стандартные глобальные строки клиента.

Русский перевод предмета добавляется отдельным блоком внизу стандартной
подсказки. Оригинальные данные остаются видимыми — это безопаснее для кастомного
клиента и не ломает игровые ссылки.

## Кастомные задания сервера

Неизвестные задания автоматически записываются в SavedVariables:
`WTF/Account/<ACCOUNT>/SavedVariables/ProjectEpoch-Ru.lua`.

После выхода из игры перенесите их перевод в `Data/Custom/QuestData_Custom_RU.lua`. Формат и
готовый пример находятся в самом файле. Если известен числовой ID задания, аддон
сможет подставлять перевод после принятия. Поле `originalTitle` позволяет найти
задание еще в окне предложения по точному английскому названию.

Неизвестные предметы и заклинания сохраняются соответственно в
`RUQL_MissingItems` и `RUQL_MissingSpells`. Файлы для ручных переводов:
`Data/Custom/ItemData_Custom_RU.lua` и `Data/Custom/SpellData_Custom_RU.lua`.

NPC собираются автоматически при наведении, выборе целью и разговоре. Игровые
объекты старый API не снабжает надежным ID, поэтому они сохраняются по сочетанию
зоны и английского имени.

Полный порядок экспорта в CSV и обратной сборки описан в `docs/WORKFLOW_RU.md`
в корне проекта.

## Ограничения аддона

Аддон запускается после входа персонажем, поэтому он не может переводить экран
авторизации и создания персонажа. Для полной базы стандартных заклинаний нужен
русский `Spell.dbc` той же версии клиента; подмена самого DBC уже является
клиентским патчем, а не аддоном. Этот проект будет переносить данные из DBC в Lua
и показывать перевод через подсказки, оставаясь обычным аддоном.

## Источник стандартной базы

Русские строки генерируются из world database проекта AzerothCore WotLK. Скрипт
`tools/generate_azerothcore_ru.py` оставлен в репозитории для воспроизводимой
пересборки базы. Лицензия источника базы: GPL-2.0.
